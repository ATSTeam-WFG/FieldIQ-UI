The FieldMT should start with an onboarding process. Any visiting user should see onboarding questionare for what kind of user they are, etc.
1. We should start with asking if they are individual title sales reps or small-mid size team of agency.
2. If its a individual sales rep, we take them to a signup page. If its a agency, we ask them if they are a sales rep or a manager.
3. If they are sales rep, should give them option to use this individually if they want to, for personal growth and field work tracking. Or else they can ask their manager to create a organization account here and send invites to all thier sales reps
4. If they are a manager, they should see a sign up page for creating their account (add an topion where a manager while creating the account can also act as a sales rep in his/her own team). Once an account is created, they should register thier agency by giving basic details like name of agency, state or opertaion, etc. Once the agency is registered, they should see option to invite their sales reps. This invite form will be same as the one we have for inviting reps in the manager view invite rep.

I also want to add a sign up screen at the /signup route which helps any user sign up. We should be able to switch from login to sign and vice-a-versa. The user should be able to sign up with email+password or SSO(Google/Microsoft)

Lets keep the UI consistent everywhere, same responsive design, reuse the components that have already been developed if needed and only develop new components if necessary. Keep everything else the same.
