# COLOR SCHEMA AND BRAND IDENTITY
---

## BRAND PERSONALITY
- Professional
- Stable
- Luxury but restrained
- Enterprise dashboard aesthetic
- Clean, modern, ergonomic
- Strong hierarchy and whitespace

---

# LIGHT MODE

## Background System
- Primary background: #fafaf9
- Card background: #ffffff
- Subtle surface sections: #f5f3ef

## Top Navigation
- Background: linear-gradient(135deg, #000000, #1a1a1a)
- Text: #fafaf9
- Active item underline: #c4a574

## Sidebar
- Background: #fafafa
- Text: #1a1a1a
- Active item: thin gold border (#c4a574)

## Accent Gold (Use Sparingly)
- #c4a574
- #a68751
- #d4b584

Use gold ONLY for:
- Active states
- KPI highlights
- Button borders
- Thin top borders on cards
- Focus rings

Do NOT use gold as large background fills.

## Typography
- Headings: #000000
- Body text: #3f3f46
- Muted text: #71717a
    
## Buttons
Primary Button:
- Background: #000000
- Text: #fafaf9
- Hover: subtle gold border glow (#c4a574)

Secondary Button:
- Border: #c4a574
- Text: #c4a574
- Hover: filled gold with black text

Ghost Button:
- Text: #1a1a1a
- Hover background: #f4f4f5

## Layout Structure
Create:
- Top navigation bar
- Left sidebar navigation
- Main dashboard area
- 4 KPI cards (minimal design)
- Data table section
- Chart section using muted slate tones (#334155, #475569)
- Clean 8px spacing system
- Border radius 6–8px
- Subtle professional shadow (soft and minimal)

Avoid heavy shadows.

# UX RULES
- Avoid bright or saturated colors
- Avoid excessive gold usage
- Avoid overly rounded corners
- Maintain strong hierarchy
- Prioritize whitespace
- Keep layout clean and executive
- Make it feel like a premium enterprise platform

Style reference: Stripe meets Goldman Sachs meets Linear.
